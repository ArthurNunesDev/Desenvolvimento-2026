## 📖 Sobre o projeto

O **Desenvolvimento 2026** é um portfólio pessoal desenvolvido para apresentar, de forma organizada, informações acadêmicas, conhecimentos técnicos, projetos e formas de contato.

O projeto foi desenvolvido como uma página web estática, com foco em uma interface simples, objetiva e responsiva.

A página reúne as principais informações em uma única experiência de navegação, utilizando uma barra de navegação superior para acessar diretamente cada seção.

---

## 🎯 Objetivo

O principal objetivo do projeto é criar uma apresentação digital da trajetória acadêmica e dos conhecimentos adquiridos na área de desenvolvimento de software.

O portfólio também funciona como uma forma de documentar a evolução durante o curso e apresentar projetos desenvolvidos ao longo da formação.

Entre os objetivos do projeto estão:

* Apresentar informações acadêmicas;
* Demonstrar conhecimentos técnicos;
* Apresentar projetos desenvolvidos;
* Centralizar informações de contato;
* Praticar desenvolvimento Front-end;
* Aplicar conceitos de HTML e CSS;
* Trabalhar com organização e estruturação de uma página web;
* Publicar um projeto utilizando GitHub Pages.

---


## 🖥️ Interface

A interface foi desenvolvida como uma página única, organizada em diferentes seções.

### Navegação

O cabeçalho possui links para:

* **Sobre Mim**
* **Formação**
* **Conhecimentos**
* **Projetos**
* **Contato**

A navegação utiliza âncoras HTML para direcionar o usuário diretamente para cada parte da página.

## 🧩 Seções do portfólio

### 👤 Sobre Mim

A seção inicial apresenta uma introdução sobre o estudante e sua área de formação.

Também são apresentados alguns dados resumidos, como:

* Idade;
* Período atual do curso;
* Quantidade de projetos.

Além da apresentação principal, existe um card com informações acadêmicas.

---

### 🎓 Formação Acadêmica

A seção apresenta cursos e formações complementares.

Atualmente são apresentados:

* Técnico em Eletrotécnica;
* Curso de Computação;
* Curso de Framework Adianti e PHP.

### 💻 Conhecimentos

## 🎨 Referência visual

A construção visual do portfólio teve como referência o template **Picto — Personal Portfolio**, disponibilizado no Figma.

A referência foi utilizada principalmente para estudar:

* Organização das seções;
* Hierarquia visual;
* Estrutura de portfólio pessoal;
* Apresentação de projetos;
* Utilização de cards;
* Organização do conteúdo;
* Espaçamento e composição da interface.

A implementação, entretanto, foi desenvolvida em HTML e CSS de acordo com a estrutura e os requisitos deste projeto.
